Vibecode your first webpage

By the end you will have a real webpage with its own link that anyone can open. It costs nothing and takes about 20 minutes.

What you need
  • A computer with a web browser
  • An email address (to make a free GitHub account)
  • A free AI chatbot. Pick one from Popular Tools.

Part 1: Make the page with AI

  1. Decide what your page is about

    Keep it small. One page about one thing: yourself, your pet, a favorite recipe, a club, a tiny game.

  2. Ask the AI to build it

    Open your chatbot and describe the page. Copy this prompt and change the words in [brackets]:

    Prompt

    Build me a one-page website about [my dog Mochi]. Include [a short intro, three fun facts, and a list of her favorite things]. Make it look [playful and colorful] and work well on phones. Put everything (HTML, CSS, and JavaScript) in a single file called index.html. Do not use any outside images or libraries.

    Why one file? A single index.html is the easiest thing to publish. You only have one thing to copy.

  3. Look at it and ask for changes

    Most chatbots show a preview of the page. Talk to the AI the way you would talk to a designer:

    • “Make the title bigger and change the background to light blue.”
    • “Add a button that shows a random fun fact.”
    • “The text is hard to read on my phone. Fix it.”

    Repeat until you like it. This back-and-forth is vibecoding.

  4. Copy the final code

    When you are happy, send this so you get the whole page in one piece:

    Prompt

    Give me the complete, final index.html in one code block.

    Click the Copy button on the code block. Keep this tab open.

Part 2: Put it online with GitHub

GitHub stores your file for free and turns it into a live website with a feature called GitHub Pages.

  1. Create a free GitHub account

    Go to github.com/signup. Enter your email, a password, and a username, then verify your email.

    Choose your username with care. It becomes part of your website's address.

  2. Create a repository

    A repository (“repo”) is a folder for your project.

    1. Click the + in the top right corner, then New repository.
    2. Type a name with no spaces, such as my-first-site.
    3. Choose Public.
    4. Turn on Add a README file.
    5. Click Create repository.

  3. Add your page

    1. In your new repo, click Add file, then Create new file.
    2. Name the file exactly index.html (all lowercase).
    3. Click in the big empty box and paste the code from the AI.
    4. Click the green Commit changes button, then Commit changes again in the pop-up. “Commit” just means save.

  4. Turn on GitHub Pages

    1. Click the Settings tab at the top of your repo.
    2. Click Pages in the left sidebar.
    3. Under “Build and deployment,” set Source to Deploy from a branch.
    4. Under Branch, choose main and / (root), then click Save.

  5. Visit your live site

    Wait a minute or two, then refresh the Pages settings screen. Your link appears at the top. It looks like this:

    https://your-username.github.io/my-first-site/

    Open it. Send it to a friend. You have a website.

  6. Keep improving it

    1. Go back to the AI and ask for a change, then ask for the complete index.html again.
    2. In your repo, click index.html, then the pencil icon to edit.
    3. Select everything, delete it, and paste the new code.
    4. Click Commit changes. Your live site updates in about a minute.

If something goes wrong

My link shows a “404” page

Wait a few minutes and refresh. If it still fails, check that the file is named exactly index.html, that it sits at the top level of the repo (not inside a folder), and that Pages is set to the main branch.

I don't see “Pages” working in Settings

On a free account the repo must be Public. Go to Settings, scroll to the bottom, and change the visibility to Public.

My changes are not showing up

Give it a minute, then do a hard refresh: Ctrl + Shift + R on Windows or Cmd + Shift + R on Mac.

The page looks broken or a button does nothing

Tell the AI exactly what you see and what you expected. Paste any error message. Then replace your file with the corrected code.
