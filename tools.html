Popular Tools

There are two ways in: tools made for building apps, and the everyday AI chatbots that can write code too.

  • Goal: choose a tool that fits you

How to choose

Start from your situation, not from the longest feature list.

New to all of this?

Pick a tool marked Beginner friendly. Use the filter below to see only those.

Already use an AI chatbot?

Stay there. The frontier models can write a full webpage for you, and that is what the DIY lesson uses.

Have a specific goal?

Check the labels. Some tools focus on one job, such as building games.
