Vibecoding using frontier models

Essentials for more advanced vibecoding

You do not need these for your first page. They come in when a project grows, for example when you want a custom domain or need to store user data.

  • GitHubgithub.comStores your code and its history, and can host simple sites for free.Code storage (opens in a new tab)
  • Vercelvercel.comPublishes web apps to the internet, usually straight from a GitHub repo.Hosting (opens in a new tab)
  • Supabasesupabase.comA ready-made backend: a database, user sign-in, and file storage.User database (opens in a new tab)
  • Appwriteappwrite.ioAn open-source backend with a database, user sign-in, and file storage. An alternative to Supabase.User database (opens in a new tab)
  • GoDaddywww.godaddy.comSells domain names, for when you want an address like yourname.com.Custom domain (opens in a new tab)
